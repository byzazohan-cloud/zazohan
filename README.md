# ZAZO PLAYER V1.2.3 FIX

Bu sürüm V1.2.2 üzerindeki yayın öncesi hata düzeltmelerini içerir.

- Müzik ekranındaki bozuk HTML fragment işaretleri kaldırıldı.
- Silinen yerel/indirilen medya o anda çalıyorsa oynatma tamamen durdurulur.
- Silinen medya için blob URL ve oynatma konumu temizlenir.
- Service Worker yalnızca gerçek uygulama kabuğu dosyalarını eşleştirir; eski cache'ler temizlenir.
- Favori/listedeki internet içeriği indirilmişse çevrimdışı kopyaya otomatik yönlenir.
- Video Media Session oynatma komutu kapalı oynatıcıyı yeniden açabilir.
- İndirme tamamlanırken kullanıcı başka içeriğe geçtiyse oynatıcı gereksiz yenilenmez.
